Project Attila — Demographic Simulator

An aspatial model of Imperator: Rome's population growth & migration under the Project Attila Demographic Rebalance. It reads the mod's real pa_demographics_modifiers.txt values (81 era × rank × band rates) and reproduces a full campaign's demography in a fraction of a second, so the calibration can be tuned without hour-long in-game runs. The dashed line is a real 1,243-year in-game run (304 BCE → 940 CE) of the Roman regions; drag the knobs and watch the model track it.

Project Attila demographic model — JavaScript port of the calibration simulator, verified identical to the Python engine to machine precision. The model is deterministic (a mean-field expectation, no Monte-Carlo noise). “Experimental” toggles expose in-development migration variants and can behave unstably by design.
